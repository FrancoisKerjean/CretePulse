# Hotfix doublons horaires bus — 02/06/2026

## Symptôme
91 routes /230 (toutes herlas) avaient des doublons dans `departures` :
fusion des sous-grilles Mon-Fri / Sat / Sun en une seule liste. Exemple :
`["07:20","10:00","17:00","07:10","10:00","13:45","17:00","11:30","17:00"]`.

## Cause
`parse_herlas_detail` itérait tous les `timetable_time__*` d'un box sans
distinguer les `timetable_valuesWrapper` enfants. `parse_ektel_pdf` posait
le `frequency` une seule fois et appendait toutes les lignes de temps dans
la même liste.

## Fix
- Nouveau champ `bus_routes.departures_by_day jsonb` ([{days, times}]).
- `departures` reste persisté en flat sorted unique pour retrocompat lecture.
- UI rend par sous-grille quand `departures_by_day` est présent.

## Déploiement (à exécuter par Kami sur le VPS)

```bash
# 1. Appliquer la migration sur Postgres self-hosted
psql "$SUPABASE_DB_URL" -f supabase/migrations/20260602120000_bus_routes_by_day.sql

# 2. SCP des parsers corrigés
scp scripts/scrapers/buses/parsers.py vps:/opt/cretepulse/buses/
scp scripts/scrapers/buses/store.py   vps:/opt/cretepulse/buses/

# 3. Relancer le scraper (réécrit toutes les routes avec departures_by_day rempli)
ssh vps "cd /opt/cretepulse && venv/bin/python buses/buses.py"

# 4. Vérif
curl -s https://crete.direct/en/buses | grep -c "07:20"
```
